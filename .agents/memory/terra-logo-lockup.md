---
name: Terra logo lockup
description: Logo format for consistent branding across compact mobile headers.
---

Use a transparent horizontal Terra lockup in compact headers; use the solar emblem alone for the favicon and a composed social card for Open Graph. The supplied logo artwork is vertically stacked, so displaying it directly at standard header heights makes the wordmark too small.

**Why:** The source artwork must fit into existing mobile header rows while keeping both the emblem and the Terra name legible.

**How to apply:** Keep shared site branding on the horizontal lockup. When the source artwork changes, regenerate the favicon and social preview from the same brand image.
